# Homepage interaction audit

## Intended flow

1. Understand the role: Layntra connects Codex to Figma through MCP.
2. Download the release, install it, or open GitHub.
3. If setup help is needed, follow the three installation steps and real Figma import screenshot.

## Removed

- Browser product simulation.
- Integration-name strip.
- Inspect/plan/protect/apply feature cards.
- Platform explanation grid.
- Repeated final call to action.

## Verification

Passed in a real browser at 1440 × 900 and 390 × 844. Both viewports have no horizontal overflow, the install image loads, removed sections are absent, and the mobile menu exposes its expanded state.
