# Layntra roadmap

## 0.1 — Local design loop

- Bounded page and selection inspection
- Editable frame, rectangle, and text creation
- Targeted node updates
- Codex plugin packaging, tests, and security documentation

## 0.2 — Design fidelity

- Auto Layout, components, instances, variables, and styles
- Image placement with file-size and format validation
- Exported previews for visual verification
- Undo-friendly command grouping and richer error recovery

## 1.0 — Public stability

- Versioned MCP contract and compatibility tests
- Signed releases and automated packaging
- Figma Community distribution
- Contributor governance and private vulnerability reporting

Success means a new contributor completes install → inspect → create → refine
on a sample file in under ten minutes.
