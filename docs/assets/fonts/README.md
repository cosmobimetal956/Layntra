# Website fonts

The public site self-hosts the Latin subsets used by its English pages:

- Barlow Condensed, weights 500, 600, and 700.
- Inter, variable weights 400 through 700.

Both typefaces are distributed under the SIL Open Font License 1.1. The license texts are stored beside the font files as `OFL-Barlow-Condensed.txt` and `OFL-Inter.txt`.
