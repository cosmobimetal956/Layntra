What is real here, and what is simulated?

The canvas is a browser simulation of the actual workflow. The commands, target checks, editable-node model, explicit apply, read-back verification, and undo behavior mirror Layntra. This page never connects to your Figma file.

01Editable layers

Supported text, fills, positions, and frames remain editable in Figma.

02Guarded target

A changed page or selection blocks the write instead of guessing.

03Local path

Codex talks to the Figma companion over loopback on your Mac.

Install in three steps

From download to first inspection.

No token setup and no protocol knowledge. Install the Codex plugin, import the Figma companion, then check the connection.

01

Install in Codex

Clone the repository and run the included installer.

./scripts/install.sh

02

Import the Figma companion

Download the ZIP, unzip it, and import the included manifest.json.

manifest.json

03

Inspect your selection

Keep the companion open and enter this in a new Codex task.

$layntra inspect selection
