From zero to first inspection

Three steps.
No API token.

Download the release, install the Codex plugin, then import the local Figma companion from its manifest. The illustrated guide is written for first-time plugin users.

  1. 01

    Download Layntra

    Get the packaged Figma companion and the Codex plugin from the v0.1.0 release.

    Open the release →
  2. 02

    Install in Codex

    Open the repository folder and run the included installer once.

    ./scripts/install.sh
  3. 03

    Import the Figma companion

    In Figma Desktop choose Plugins → Development → Import plugin from manifest, then select manifest.json.

    Open the illustrated install guide →

Figma access varies by plan, workspace, and seat. Layntra works where Figma Design plugins are permitted; it does not bypass Figma permissions or plan restrictions.
